# Networking Basics

## 🎯 Objective

Learn the basic networking concepts that are important for cybersecurity.

## 🌐 1. IP Address

An IP address identifies a device on a network.

Example:
- IPv4: 192.168.1.10

## 🔒 2. Private vs Public IP

### Private IP
Used inside a local network.

Examples:
- 192.168.x.x
- 10.x.x.x
- 172.16.x.x to 172.31.x.x

### Public IP
Used to identify a network/device on the public Internet.

## 🌍 3. DNS

DNS (Domain Name System) translates domain names into IP addresses.

Example:

example.com → IP address

## 🔐 4. HTTP vs HTTPS

HTTP sends web traffic without encryption.

HTTPS uses encryption to protect data between the browser and website.

## 📡 5. TCP vs UDP

TCP:
- Connection-oriented
- Reliable
- Used when reliable delivery is important

UDP:
- Faster and connectionless
- Does not guarantee delivery

## 🛡️ Security Notes

Good network security practices include:

- Use strong passwords
- Keep software updated
- Use HTTPS
- Secure Wi-Fi networks
- Avoid unknown links
- Use firewalls where appropriate
